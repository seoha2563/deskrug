# DeskRug

바탕화면에 까는 **접히는 러그**입니다. 러그를 끌어서 접고, 눌러서 구기고, 다시 펼 수 있어요.
(Windows 10/11 64비트)

## 다운로드

[**Releases**](../../releases/latest)에서 `DeskRug-win32-x64.zip`을 받으세요.

1. 압축을 풉니다. 바탕화면이나 문서 같은 원하는 곳에 폴더째로 두세요.
2. `DeskRug-win32-x64` 폴더 안의 `DeskRug.exe`를 더블클릭합니다.
3. 화면 가운데에 러그가 깔립니다.

> 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있어요. 서명이 없는 개인 프로그램이라서 나오는 경고입니다.
> **추가 정보 → 실행**을 누르세요.

## 쓰는 법

- 러그의 가장자리나 모서리를 잡고 끌면 들려서 접힙니다.
- 러그 안쪽을 잡고 끌면 눌려서 밀리고 구겨집니다.
- 접힌 쪽을 다시 잡고 끌면 펴집니다.
- `Alt`를 누른 채 끌거나 마우스 오른쪽 버튼으로 끌면 러그가 통째로 이동합니다.
- 러그가 없는 곳은 클릭이 그대로 통과해서 바탕화면 아이콘이나 다른 창을 평소처럼 쓸 수 있습니다.
- 다른 창을 열면 러그는 그 창 아래로 가려집니다. (창을 최소화하면 다시 보입니다. "항상 다른 창 위에 표시"를 켜면 위에 떠 있습니다.)

## 설정

작업표시줄 오른쪽 아래(숨겨진 아이콘 `^` 안일 수 있음)의 러그 모양 아이콘을 클릭하세요.

- 사진 바꾸기: 내 사진(PNG/JPG 등)을 러그로 씁니다. 배경이 투명한 PNG가 가장 예쁩니다.
- 사진 배경 제거: 사진의 단색 배경을 지워서 모양대로 오려 냅니다.
- 크기, 뻣뻣함, 러그 펴기, 화면 가운데로
- 항상 다른 창 위에 표시
- Windows 시작 시 자동 실행
- 종료

설정은 `%APPDATA%\DeskRug` 폴더에 저장됩니다. 접어 놓은 모양은 저장되지 않아서 다시 실행하면 펴진 상태로 시작합니다.

## 지우는 법

1. 트레이 메뉴에서 "종료"
2. DeskRug 폴더를 삭제
3. (선택) `%APPDATA%\DeskRug` 폴더 삭제 — "Windows 시작 시 자동 실행"을 켰었다면 먼저 꺼 두세요.

## 소스에서 실행하기

```
npm install
npm start
```

직접 빌드하려면 `npm run pack`을 실행하세요. (Electron 기반)

> VS Code 터미널처럼 `ELECTRON_RUN_AS_NODE`가 설정된 환경에서는 앱이 바로 종료될 수 있습니다. 그럴 땐 이 환경 변수를 지우고 실행하세요.
